# Tech Lab — Tecnologia, Software e Inovação

> **Transformamos ideias em soluções digitais.**

Website oficial da Tech Lab, uma iniciativa tecnológica orientada para o desenvolvimento de software, criação de produtos digitais e prestação de serviços tecnológicos.

🌐 **Website:** https://techlabsa.vercel.app/

📍 **Localização:** Angola

---

## 📖 Sobre a Tech Lab

A Tech Lab é uma iniciativa dedicada à tecnologia e à inovação, com foco na criação de soluções digitais que ajudam empresas, empreendedores e organizações a melhorar os seus processos e a desenvolver a sua presença online.

O website funciona como ponto de apresentação da marca, permitindo aos visitantes conhecer a empresa, explorar os seus serviços e entrar em contacto para solicitar informações ou apresentar projectos.

## 🎯 Objectivos do website

- Apresentar a identidade e a proposta de valor da Tech Lab.
- Divulgar os serviços e as soluções tecnológicas da empresa.
- Facilitar o contacto com potenciais clientes e parceiros.
- Reforçar a presença digital da marca.
- Criar uma base para a futura expansão dos serviços e produtos digitais.

## 💻 Áreas de actuação

A Tech Lab pretende desenvolver soluções nas seguintes áreas, conforme os serviços efectivamente disponibilizados:

- **Desenvolvimento web:** criação de websites e aplicações web.
- **Desenvolvimento de software:** implementação de sistemas e soluções personalizadas.
- **Produtos digitais:** concepção e desenvolvimento de plataformas digitais.
- **Consultoria tecnológica:** apoio na escolha e implementação de soluções tecnológicas.
- **Formação tecnológica:** partilha de conhecimentos e desenvolvimento de competências digitais.

## 🚀 Executar localmente

### Pré-requisitos

- Node.js compatível com o projecto.
- npm.

### 1. Obter o código-fonte

```bash
git clone URL_DO_REPOSITORIO
cd tech-lab
```

Substitui `URL_DO_REPOSITORIO` pelo endereço real do repositório Git.

### 2. Instalar as dependências

```bash
npm install
```

### 3. Iniciar o servidor de desenvolvimento

```bash
npm run dev
```

Abre no navegador o endereço local apresentado no terminal.

### 4. Gerar a versão de produção

```bash
npm run build
```

### 5. Testar a versão de produção

```bash
npm run preview
```

Os comandos acima aplicam-se caso o projecto utilize Vite e tenha os respectivos scripts configurados no `package.json`.

- Não publicar chaves privadas ou credenciais.
- Utilizar HTTPS.
- Validar os dados recebidos por formulários.
- Manter as dependências actualizadas.
- Optimizar imagens e recursos estáticos.
- Garantir acessibilidade e compatibilidade com navegadores modernos.
- Evitar apresentar serviços, clientes ou resultados que não possam ser comprovados.
